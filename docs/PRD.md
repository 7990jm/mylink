# 마이링크 PRD (기능 정의서)

## 1. 프로젝트 개요
- 프로젝트명: 마이링크 (링크트리 클론)
- 목적: 운영 중인 유튜브 채널 등 여러 링크를 한 페이지에 모아 공유
- 대상 사용자: 유튜브 채널 운영자 (여러 채널 링크를 한 곳에)

## 2. 기능 목록
| 기능 | 구분 | 주차 | 상태 |
|---|---|---|---|
| 프로필 영역 (이름, 소개, 이미지) | 부가 | 2~4주 | 완료 |
| 링크 목록 표시 (Read) | 필수 | 6주 | 완료 |
| 링크 추가 (Create) | 필수 | 7주 | 완료 |
| 데이터 영구 저장 (Firebase) | 필수 | 9주 | 완료 |
| 링크 수정/삭제 (Update/Delete) | 필수 | 10주 | 완료 |
| 구글 로그인 | 필수 | 11주 | 완료 |
| 개인 URL (/username), 프로필 수정, 보안 규칙 | 필수 | 12주 | 완료 |
| 클릭 수 통계 | 선택 | 13주 | 완료 |
| Vercel 배포, OG 이미지, 랜딩 페이지 | 필수 | 14주 | 완료 |

## 3. 상세 기능 정의
### 링크 목록 표시 (Read)
- 동작: 링크 배열을 순회하며 각 링크를 버튼으로 세로 배치
- 출력: 아이콘 + 제목 + URL, 클릭 시 새 탭으로 이동
- 데이터: `{ id, title, url, icon }` (유튜브 주소면 📺, 그 외 🔗)

### 링크 추가 (Create) — `/mypage`
- 동작: 추가 버튼 클릭 → 입력값 가져오기 → 검증 → 목록에 추가 → 화면 자동 갱신 → 입력 칸 비우기
- 입력: 링크 제목, 링크 주소
- 예외 처리 (추가 버튼을 눌렀을 때 검증)
  | 상황 | 메시지 |
  |---|---|
  | 제목 없음 | 제목을 입력해주세요 |
  | 주소 없음 | 주소를 입력해주세요 |
  | 주소 형식 오류 (예: abc) | 올바른 주소를 입력해주세요 |
- 실패 시 빨간색 경고 + 입력 칸 유지 / `http(s)://` 없으면 `https://` 자동 보완
- 저장: 브라우저 localStorage (새로고침해도 유지, 단 이 브라우저에서만 보임) → 9주차 Firebase

### 프로필 수정 — `/mypage`
- 입력: 이름(채널명, 필수), 소개글, 프로필 이미지 주소(선택, 비우면 이름 첫 글자)
- 동작: 프로필 저장 버튼 → 검증 → 저장 → 메인 페이지에 반영

## 4. 사용자 시나리오
- 방문자: 민수는 유튜버의 채널 목록을 보기 위해 인스타그램 프로필의 마이링크 URL을 클릭한다 → 프로필과 링크 목록을 확인한다 → 원하는 링크를 눌러 해당 사이트로 이동한다.
- 소유자: 민수는 새 유튜브 채널을 추가하기 위해 `/mypage`에 접속한다 → 제목과 주소를 입력하고 추가 버튼을 누른다 → 목록 맨 아래에 새 링크가 나타난다.

## 5. 와이어프레임
```
 /                          /mypage
┌──────────────────┐       ┌──────────────────────┐
│  (프로필 이미지)   │       │ 내 링크 관리  ← 내 페이지│  상단: 제목
│   채널명          │       ├──────────────────────┤
│                  │       │ 링크 제목 [________]  │  중간: 폼
│  소개글           │       │ 링크 주소 [________]  │
├──────────────────┤       │ [      추가하기      ] │
│ [📺 메인 채널  ]  │       ├──────────────────────┤
│ [📺 서브 채널  ]  │       │ (프로필 수정 폼)       │  하단: 목록
│ [🔗 기타 링크  ]  │       │ [📺 메인 채널 ] [삭제] │
│   내 링크 관리 →  │       │ [📺 서브 채널 ] [삭제] │
└──────────────────┘       └──────────────────────┘
```
